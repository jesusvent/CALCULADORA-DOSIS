# Calculadora de Dosis Veterinaria

Calculadora de dosis de fármacos para perro y gato: búsqueda por principio
activo o nombre comercial, protocolos combinados, cálculo de infusiones a
ritmo constante (CRI), búsqueda en vivo en CIMAVET/CIMA, y base de datos
personal de fármacos y protocolos.

App web estática (sin servidor propio, sin build): abre `index.html` o
publícala tal cual (por ejemplo con GitHub Pages).
